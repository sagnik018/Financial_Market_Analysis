# Financial Market Analysis using Yahoo Finance, MySQL & Python

## Objective
To analyze real-world financial market data using Yahoo Finance, store it
in MySQL, perform time-series analysis using Python, and generate
structured reports.

## Data Source
Market data is retrieved from Yahoo Finance using the `yfinance` Python
library, which provides access to publicly available stock price data.

## Tools Used
- Python (Pandas, yfinance, SQLAlchemy)
- MySQL Workbench
- Excel Reporting
- Matplotlib

## Workflow
1. Fetch financial data from Yahoo Finance
2. Store data in MySQL database
3. Query data using SQL
4. Perform EDA and financial analysis
5. Generate Excel reports and visualizations

## Key Analysis
- Closing price trends
- 20-day moving average
- Daily return calculation
