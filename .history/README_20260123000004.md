# 📊 Financial Market Analysis System


This project delivers an **end-to-end financial data pipeline** that automatically collects market data from external APIs, stores it securely in a **MySQL database**, transforms it into analysis-ready formats, and produces **insightful analytics and reports**.

Think of it as a **data highway**: raw market data comes in, gets cleaned and structured, and exits as decision-ready insights. The solution is modular, scalable, and designed with both **technical teams and business stakeholders** in mind.
---

## 🚀 System Overview

This project implements a **production-aligned financial analytics system** that transforms raw stock market data into **decision-ready insights**.

It follows a modular pipeline approach:

**API → Database → Transformation → Analysis → Reporting → AI Insights**

### Designed for
- Data engineers  
- Financial analysts  
- Interview demos  
- Academic & portfolio projects  

---

## 🧠 Core Capabilities

### 🔹 Automated Data Ingestion
- Fetches real-time & historical market data using **Yahoo Finance (`yfinance`)**
- Stores raw data safely in structured formats

### 🔹 Centralized SQL Storage
- MySQL database with defined schema
- Ensures data integrity and time-series consistency

### 🔹 Advanced Analytics
- Exploratory Data Analysis (EDA)
- Volatility, CAGR, trend detection
- Risk–return classification

### 🔹 AI-Ready Reporting
- Rule-based investment summaries
- Optional LLM-powered narrative generation
- CSV outputs ready for dashboards or BI tools

---

## 🏗️ High-Level Architecture

### Data Source (API)
Market data via `yfinance` (stocks, prices, indicators)

### Ingestion Layer
Python scripts validate, clean, and load data

### Database Layer
MySQL for structured, queryable storage

### Transformation Layer
JSON → CSV → analytics-ready tables

### Analytics Layer
Python + SQL (EDA, metrics, visualizations)

CSV reports, Jupyter notebooks, AI summaries

## 🔍 Key Modules Explained

### 🗄️ Database Schema (`schema.sql`)

-   Defines structured financial tables
    
-   Primary keys, data types, constraints  
    **Business Value:** Reliable, scalable time-series storage
    

### 🔄 API to MySQL (`api_to_mysql.py`)

-   Fetches stock data
    
-   Cleans & validates responses
    
-   Inserts into MySQL  
    **Business Value:** Eliminates manual data collection
    

### 📥 Fetch from MySQL (`fetch_from_mysql.py`)

-   Executes SQL queries
    
-   Extracts historical data  
    **Business Value:** Reproducible, auditable analytics
    

### 🔁 JSON to CSV (`json_to_csv.py`)

-   Converts raw API responses into CSV  
    **Business Value:** Easy integration with Excel, BI, ML
    

### 📊 Exploratory Data Analysis (`eda.ipynb`)

-   Trend detection
    
-   Volatility analysis
    
-   Summary statistics  
    **Business Value:** Turns raw data into insights
    

### 🤖 AI Investment Summary (`ai_summary.py`)

-   Classifies stocks using:
    
    -   Volatility (Risk)
        
    -   CAGR (Growth)
        
-   Generates investor-friendly summaries
    
-   Enhancementsnhancement using local LLM (Ollama)  
    **Business Value:** Converts metrics → narratives → decisions
